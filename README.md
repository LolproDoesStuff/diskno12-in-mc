# Disk. No. 12 in Minecraft
Stupidly simple resource pack that replaces the disk 13 with "Disk No. 12" by shinyflvres into Minecraft

## What have you added?
Basically 3 things: I retextured the disk so that the pixels in the centre match the album cover from "Disk. No. 12", i modified the language to replace the text "C418 - 13" so make sure to use the "English (US)" language while using this pack, lastly i simply replaced the song with the new one.

## How to I install this?
Like any other texure pack, it's really simple.

1. Download the pack from Modirinth;
2. Minecraft Options > Resource Packs > Open Resource Pack folder;
3. Drag & drop/copy & paste the downloaded .zip file into that folder;
4. Enable the pack in game;
5. Done, now you can play "Disk. No. 12" in game by playing the disk "13"
